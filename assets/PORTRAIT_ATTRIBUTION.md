# Demo profile portraits

100 profile portraits are provided by [Random User Generator](https://randomuser.me/photos).

Random User states these photos were selected from the authorized section of UI Faces. Its linked [archived UI Faces FAQ](https://web.archive.org/web/20160811185628/http://uifaces.com/faq) permits authorized portraits on live products and instructs developers to use fictional names. These portraits accompany fictional demo employee records and do not imply employment or endorsement.

The underlying photos are not represented as public domain or covered by the API software license. See `sources.json` for exact original URLs and retrieval details.
